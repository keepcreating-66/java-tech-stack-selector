---
description: 用业务场景预设填写 Java 技术选型默认值，并继续确认架构
---

调用 `tech-stack-selector` Skill。将 `$ARGUMENTS` 解析为预设编号或名称：

| 输入 | 业务场景 |
| --- | --- |
| `1`、`enterprise` | 企业管理 |
| `2`、`ecommerce` | 电商 |
| `3`、`ai` | AI 应用 |
| `4`、`custom` | 自定义 |

没有参数时先让用户选择上述业务场景。历史输入 `microservice` 或旧编号 `4` 若上下文明确表示“微服务架构”，应说明它属于架构选项，并继续询问业务场景；不要将它当成会直接生成工程的预设。

选定场景后，**仍须询问或确认架构**：`单体`、`模块化单体`、`微服务`。随后展示预设填入的默认值，允许修改项目名、模块/服务、数据库、ORM、缓存、安全、API 文档和可支持的架构组件。选择输出方式后展示完整总览，经用户确认才选择目录并写文件。取消不写文件。

预设不包含尚未实现的 Flowable、XXL-Job、RabbitMQ、Spring AI、Milvus、Nacos 等组件。它们可记录为未来需求，不能作为当前已生成能力展示。

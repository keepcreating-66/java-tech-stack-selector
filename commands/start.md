开始Java后端项目技术选型流程。

请按照以下步骤引导用户，使用**按钮式交互**让用户点击选择：

1. **收集项目基本信息**（项目名称、类型、Java版本、构建工具）
2. **选择核心技术栈**（应用框架、数据库、ORM、缓存、认证、API文档）
3. **选择可选模块**（消息队列、搜索引擎、工作流、定时任务）
4. **选择扩展模块**（微服务组件、工具库、监控、部署）
5. **确认选择并生成输出**

## 交互流程

### 第一步：欢迎语和基本信息收集

```markdown
👋 欢迎使用Java后端项目技术选型助手！

请告诉我你的项目基本信息：

**1. 项目名称**
直接输入项目名称即可，例如：`my-shop`

---

**2. 项目类型**（点击选择）

[🔵 单体应用](#单选:monolith)   [🟢 模块化单体 (推荐)](#单选:modular)   [🔷 微服务](#单选:microservice)   [🔶 单体/微服务可切换](#单选:switchable)

---

**3. Java版本**（点击选择）

[JDK 8](#单选:jdk8)   [🟢 JDK 17 (推荐)](#单选:jdk17)   [JDK 21](#单选:jdk21)

---

**4. 构建工具**（点击选择）

[Maven (推荐)](#单选:maven)   [Gradle](#单选:gradle)
```

### 第二步：核心技术栈选择

展示必选模块选项，使用按钮让用户点击选择：
- 应用框架
- Web层（Spring WebMVC / Spring WebFlux）
- 关系型数据库（含版本选择）
- ORM框架
- 连接池
- 缓存方案
- 认证框架
- API文档

### 第三步：可选模块选择

- 消息队列
- 搜索引擎
- 工作流引擎
- 定时任务

### 第四步：扩展模块（按钮多选）

仅当用户选择微服务架构时询问：
- 服务注册/配置中心
- API网关
- RPC框架
- 限流熔断
- 分布式事务

### 第五步：工具库和监控（按钮多选）

- 工具库（多选）
- 监控方案（多选）
- 部署方案

### 第六步：预设方案（卡片式按钮）

```markdown
📋 是否使用预设方案快速配置？

> ## [🅰️ 企业级管理系统](#预设:enterprise)
> 适用：后台管理、OA、ERP、CRM

> ## [🅱️ 电商系统](#预设:ecommerce)
> 适用：商城、交易平台

> ## [🤖 AI应用平台](#预设:ai)
> 适用：AI服务、RAG、Agent

> ## [🔧 微服务架构](#预设:microservice)
> 适用：大型分布式系统

> ## [✨ 自定义配置](#预设:custom)
> 继续手动选择每个模块
```

### 第七步：确认与修改

展示完整的技术栈清单，等待用户确认或修改。

```markdown
**是否需要修改？**

[ ✅ 确认，继续生成 ](#操作:confirm)   [ ✏️ 修改某个模块 ](#操作:modify)   [ 🔄 重新开始 ](#操作:restart)
```

### 第八步：生成输出

```markdown
📁 请选择输出方式：

[ 📄 生成技术栈配置文件 (JSON) ](#输出:json)   [ 📦 生成Maven依赖片段 (XML) ](#输出:xml)   [ 📝 生成项目提示词 ](#输出:md)

[ 🎯 直接生成项目框架 (仅Cursor) ](#输出:project)   [ ✨ 全部生成 ](#输出:all)
```

根据用户选择生成：
- 技术栈配置文件（JSON）
- Maven依赖片段（XML）
- 项目提示词（Markdown）
- 项目框架（仅Cursor）

## 参数支持

如果用户提供了参数 "$ARGUMENTS"，尝试解析为项目名称。

## 快捷命令

- `/start` 或 `/tech-stack` - 开始技术选型
- `/start my-project` - 使用项目名称开始
- `/preset 1` - 使用预设方案

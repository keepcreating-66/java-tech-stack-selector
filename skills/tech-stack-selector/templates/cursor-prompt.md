# Cursor 项目创建指令模板

本指令供用户在完成架构与技术选型后明确调用 Agent。它不会由 VSIX 自动发送。使用前将下面的标识替换为用户已确认的值。

```json
${TECH_STACK_JSON}
```

请在 `${OUTPUT_DIRECTORY}` 创建 `${PROJECT_NAME}`。采用 `${PROJECT_TYPE}` 架构，业务模块或服务为 `${MODULES}`。按已确认配置生成对应的 Maven 工程，不改变架构或擅自增加技术组件。

1. 检查目标目录不存在；若已存在，请用户换名或换目录，保留已有文件。
2. 按所选架构生成真实边界：单体一个应用；模块化单体由 common、业务模块与 bootstrap 组成；微服务有独立业务服务及用户选择的网关。
3. 根据已选数据库、ORM、缓存、认证和 API 文档生成依赖、配置和最小 CRUD 示例。无缓存不添加 Redis；JPA 不生成 MyBatis-Plus Mapper。环境变量中不写入真实凭据。
4. 提供健康端点、测试、数据库初始化说明和运行 README。依赖外部服务的步骤注明前提条件。
5. 实际运行可用的构建与启动检查。报告“已创建文件”“构建通过/失败/未运行”“启动通过/失败/未运行”及证据，不能仅根据文件存在宣称业务系统完成。

当前确定性 VSIX 生成范围见 `references/compatibility.md`。若要求超出范围的设计，应先说明新增工作范围和验证要求。
